# HR-Data-Analytics

## Project Overview

The HR Presence Insight Dashboard is an interactive Power BI dashboard designed to monitor employee attendance behavior, work-from-home (WFH) trends, and sick leave (SL) patterns.

This dashboard helps HR teams and management:

- Track overall workforce presence
- Analyze attendance trends over time
- Identify employees with low attendance
- Monitor WFH and sick leave usage
- Support workforce planning and HR decision-making

The dashboard provides a centralized view of employee presence metrics using dynamic visuals and KPI indicators.

## Insight

The dashboard reveals a workforce with:
- Strong overall attendance
- Moderate hybrid work adoption
- Low sick leave usage
- Clear weekday attendance behavior patterns

The strongest trends identified are:
- Attendance decreases toward Friday
- WFH peaks on Friday
- Sick leave is highest on Monday
- Some employees show unusual attendance behavior requiring HR attention
